kiliseOS™ Version 0.4.x

1. What is kiliseOS?
-------------------

kiliseOS™ is an Open Source operating system project that is
compatible with applications and drivers written for the Microsoft® Windows™ NT
family of operating systems (NT4, 2000, XP, 2003, Vista, 7).

More information is available at: https://github.com/justlimorina/kiliseos


2. Credits & Foundation
-----------------------

kiliseOS is built upon the robust foundations of the ReactOS® and Wine
projects. We acknowledge and give immense credit to the ReactOS development
team, the Wine development community, and all upstream contributors who made
this open NT-compatible architecture possible.


3. Future Compatibility
-----------------------

kiliseOS focuses on modernizing the user interface (including Material Design 3
principles and modern icon sets) while maintaining deep binary compatibility
with Windows NT applications and drivers.


4. Is kiliseOS legal?
--------------------

Yes.
All code in kiliseOS is licensed under open source licenses (chiefly GPL, LGPL,
and BSD). Clean-room reverse engineering and open documentation are used to
ensure legal software implementation.
